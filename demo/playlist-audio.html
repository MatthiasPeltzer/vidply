VidPly - Audio Playlist

Mixed Media Playlist Video Playlist HLS Streaming

Features Demonstrated

  • Previous/Next buttons - Navigate between tracks seamlessly
  • Auto-advance - Automatically plays the next track when one ends
  • Track info display - Shows current track number, title, artist, and duration
  • Duration badges - YouTube-style duration overlays on thumbnails
  • Track descriptions - Brief descriptions for each track (WCAG accessible)
  • Interactive playlist panel - Click any track to jump to it instantly
  • Album art support - Display thumbnail images for each track
  • Per-track captions - Lyrics and translations for selected tracks
  • Per-track chapters - Navigate song sections with chapter markers
  • Active track highlighting - Visual indicator for currently playing track
  • Full keyboard navigation - Tab, Enter, and Space for playlist control
  • Responsive design - Adapts to mobile, tablet, and desktop screens
  • Accessibility features - ARIA labels with duration announced to screen readers

Perfect For

  • Music Players - Albums, playlists, artist collections
  • Podcasts - Episode series
  • Audiobooks - Chapter navigation
  • Audio Courses - Lesson sequences
  • Language Learning - Audio lessons with transcripts

Additional Keyboard Shortcuts

  • Shift + N - Next track
  • Shift + P - Previous track
