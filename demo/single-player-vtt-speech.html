VTT Speech Audio Description

This player uses data-audio-description-mode="vtt_speech" with a kind="descriptions" WebVTT track. There is no described video swap (data-desc-src is omitted). When you enable the AD button, VidPly pauses at each description cue, speaks the text via the browser’s speech synthesis API, then resumes playback. Open the transcript panel to read the same cues as text.

How to try it

  1. Start playback and click the AD button in the control bar.
  2. When a visual description cue becomes active, the video pauses and the cue is spoken aloud.
  3. Playback resumes automatically after the narration finishes.
  4. Use the transcript button to read description text without TTS (audioDescriptionSpeech: false in code).

For described-video swap (pre-mixed MP4/WebM), see Single Video (Floating Player).
